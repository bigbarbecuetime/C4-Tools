Crop

Use & codes for color and formatting. For example, &6 makes text gold and &l makes it bold. See Formatting codes (Java Edition set only: 0-9a-f, k/l/m/n/o/r). Also applies to the seed name below.

Use minecraft for normal farmland. Upload a custom farmland file from the farmland designer to use another type.

Blank fertilizer defaults to BONE_MEAL, or MAGMA_CREAM for nether-only / lava-hydrated crops.

mcMMO (optional)

Used only when the mcMMO plugin is installed. Harvesting grants Herbalism XP, and double drops follow mcMMO's Herbalism skill (Green Terra triples).

Seed

0 = this crop's seed will never drop from grass/ferns/bushes, in any biome.

Seeds drop from grass and small plants in the crop's natural biomes. grass_seeds.drop_chance controls how often any seed drops. This weight chooses which seed drops. A weight of 0.3 is three times as likely as 0.1. Choose "consumable is seed" when the harvest and seed are the same item, like a carrot.

Biomes

Full speed inside natural biomes, otherwise growth is multiplied by this rate. Leaving this empty is full speed everywhere.

Harvest results

Effects

Sounds and particles played crop-wide. on_punch fires when the crop is punched/broken, on_harvest when a ripe crop is harvested, and ambient repeatedly while it grows. Each growth stage can override these (see a stage's "stage effects").

Consumables

Harvest results and the seed reference consumable ids. Create and edit those consumables in the consumable designer, then drop its .yml into plugins/C4/consumables/.

Stages

Add items, blocks, or heads to each stage. Positions start at the center of the farmland. Each element turns around its own center. Heads accept a skin URL or texture value.
