Start from a value

Paste a head's base64 texture value, a textures.minecraft.net skin URL, or a bare texture hash, then load it onto the canvas to edit.

Upload a skin PNG to paint over it. Download saves the skin.

A texture value links to a skin hosted by Mojang. It does not contain the pixels. The painted skin is uploaded to MineSkin, which puts it on Mojang's texture server and hands back the value.

Kept in this browser only (localStorage), never sent anywhere but MineSkin. Without a key you share the free tier's limit of about 20 skins per minute. Keys come from account.mineskin.org.

 

Using it

Drop the value into any C4 texture field: a station or tool in config.yml, a head consumable, or a type: head crop stage element in the crop designer. Heads with the same value stack.
