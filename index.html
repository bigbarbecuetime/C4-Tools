C4

Config Tools

Crops · Consumables · Cooking · Crafting

Tools for building the plugin's YAML config files. Each tool generates files you drop into plugins/C4/<folder>/.

Crop Designer

Build crop stages with items, blocks, and player heads. Export crop files for farming/.

Farmland Designer

Create farmland and choose how it gets water. Export files for farming/farmland/.

Consumable Designer

Create food, effects, recipes, preparation steps, and addictions. Export files for consumables/.

Head Painter

Paint a player head or edit an existing texture. Copy the finished texture value.

Config Editor

Edit the main settings, groups, visuals, and vanilla crops. Export config.yml.
