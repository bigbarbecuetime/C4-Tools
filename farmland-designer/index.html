Identity

Use & codes for color and formatting. For example, &6 makes text gold and &l makes it bold. See Formatting codes (Java Edition set only: 0-9a-f, k/l/m/n/o/r).

Tilling

Source blocks are the original blocks to be tilled. The tilled block is used for the texture of the tilled farmland. Multiple source and tilled blocks can be considered the same farmland, in this case list them in order for each. (e.g. SAND, RED_SAND keeps each sand its own color). The preview only shows the first of this list. For a full list of blocks see here

Water model

The block that hydrates this farmland. WATER by default; use LAVA for nether soils (crimson/warped/soul).

Per-biome baselines

Initial/ambient water content by biome key. When this farmland is in these biomes it will start (and dry back to) these values.
